# Installation

## Initialize the registry

```bash
npx shadcn-lynx init
```

The initializer creates `components.json`, `src/lib/utils.ts`, `src/global.css`, `tailwind.config.ts`, and the UI component directory.

## Enable Tailwind for Lynx

Install Tailwind CSS 3, the Lynx-compatible preset, and the Rsbuild integration:

```bash
pnpm add -D tailwindcss@3.4.17 @lynx-js/tailwind-preset@0.5.0 rsbuild-plugin-tailwindcss@0.1.1
```

Add the plugin to `lynx.config.ts`. Keep `pluginReactLynx` configured with CSS selectors, CSS inheritance, and the new gesture runtime because lynx-ui state variants and gesture components depend on them.

```ts
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin';
import { defineConfig } from '@lynx-js/rspeedy';
import { pluginTailwindCSS } from 'rsbuild-plugin-tailwindcss';

export default defineConfig({
  plugins: [
    pluginReactLynx({
      enableCSSSelector: true,
      enableCSSInheritance: true,
      enableNewGesture: true,
    }),
    pluginTailwindCSS({
      config: 'tailwind.config.ts',
      exclude: [/[\\/]node_modules[\\/]tailwind-merge[\\/]/],
    }),
  ],
  environments: {
    web: {},
    lynx: {},
  },
});
```

Import the generated stylesheet from the application entry:

```ts
import './global.css';
```

## Add components

```bash
npx shadcn-lynx add button
npx shadcn-lynx add dialog input
```

The CLI resolves registry dependencies, copies source into the configured `ui` alias, and prints the packages required by the selected components.

## Requirements

- ReactLynx `>=0.100.0`
- A compatible Lynx engine and Rspeedy toolchain
- `@lynx-js/lynx-ui` for headless interactive primitives
- `class-variance-authority`, `clsx`, and `tailwind-merge` where required by copied components
