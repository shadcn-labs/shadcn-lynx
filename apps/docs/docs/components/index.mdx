# Components

Open-code ReactLynx components styled with shadcn/ui conventions. Interactive behavior comes from headless `@lynx-js/lynx-ui` primitives; display-only pieces use native Lynx elements.

## Headless lynx-ui wrappers

| Component | Purpose | Install |
| --- | --- | --- |
| [Button](./button) | Press interaction and variants | `npx shadcn-lynx add button` |
| [Checkbox](./checkbox) | Boolean or indeterminate selection | `npx shadcn-lynx add checkbox` |
| [Dialog](./dialog) | Blocking modal content | `npx shadcn-lynx add dialog` |
| [Draggable](./draggable) | Free or handle-based dragging | `npx shadcn-lynx add draggable` |
| [Feed List](./feed-list) | Virtual feed, refresh, and pagination | `npx shadcn-lynx add feed-list` |
| [Form](./form) | Field state and submission | `npx shadcn-lynx add form` |
| [Input](./input) | Text input and textarea | `npx shadcn-lynx add input` |
| [Lazy Component](./lazy-component) | Viewport-driven deferred rendering | `npx shadcn-lynx add lazy-component` |
| [List](./list) | Virtualized collections | `npx shadcn-lynx add list` |
| [Popover](./popover) | Anchored floating content | `npx shadcn-lynx add popover` |
| [Radio Group](./radio-group) | Single-choice selection | `npx shadcn-lynx add radio-group` |
| [Scroll View](./scroll-view) | Bounded mixed-content scrolling | `npx shadcn-lynx add scroll-view` |
| [Sheet](./sheet) | Edge panel with snap points | `npx shadcn-lynx add sheet` |
| [Slider](./slider) | Numeric value selection | `npx shadcn-lynx add slider` |
| [Sortable](./sortable) | Drag-to-reorder collection | `npx shadcn-lynx add sortable` |
| [Swipe Action](./swipe-action) | Swipe-revealed contextual action | `npx shadcn-lynx add swipe-action` |
| [Swiper](./swiper) | Paged carousel | `npx shadcn-lynx add swiper` |
| [Switch](./switch) | On/off setting | `npx shadcn-lynx add switch` |
